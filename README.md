# 上海交通大学 349 药学考研工作平台

一个自包含的单文件网页应用，覆盖 349 药学综合备考全流程：

- 每日五门专业课考点推送（药物化学 · 药理学 · 药事管理学 · 药剂学 · 药物分析学，10 天一轮，含名词解释 / 简答题 / 论述题）
- 英语 / 政治 / 专业课 三栏任务清单（按创建时间排序，往日任务标注日期）
- 专注计时、单词本与生词本、热点经验贴聚合
- 倒计时、日程导出（.ics）、数据本地备份导出（JSON / CSV）
- 多端云同步

本仓库的 `index.html` 为自包含单文件（图片与数据均已内联，零外部依赖），可直接双击打开或托管到任意静态空间。

> 部署：GitHub Pages（main 分支根目录）。如需更新，重新推送 `index.html` 即可，地址不变。
